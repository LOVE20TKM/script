# Market Curve Combined Chart Design

## Goal

让 `script/log/dashboards/market-curve/` 默认在一张共享坐标系中展示全部可识别代币的曲线，并支持按图例显示或隐藏代币，以及在市值和币价之间切换。

## Scope

- 移除页面上的代币下拉列表。
- 服务端在未传入 `tokens` 时选择全部已知代币，但排除当前计价代币本身；保留显式 `tokens` 参数的兼容行为。
- 页面初次加载参数后自动查询完整曲线数据，不再停留在“请选择参数后查询”。
- 将每个代币的独立面板合并为一个组合图，所有曲线使用同一组时间轴和当前指标的纵轴。
- 使用可点击图例控制单个代币的显示状态；没有交易对或没有数据的代币仍可识别，但不可显示为有效曲线。
- 使用“市值 / 币价”分段按钮切换当前绘制字段，不重新请求服务端数据。
- 保留计价代币、时间范围、聚合周期和查询按钮。

## Data Flow

1. 页面发起 `meta=1` 请求，取得网络、计价代币候选和全部已知代币。
2. 页面按当前计价代币、时间范围和聚合周期发起普通数据请求，不传 `tokens`，由服务端返回默认全量系列。
3. 服务端将全部非计价代币交给既有 `query_token_series` 生成 candles、pair 和 message。
4. 页面保存完整 `series`，本地维护 `visibleTokens` 和 `metric`。
5. 组合图按所有可见且有 candles 的系列计算统一的时间点、纵轴范围和多色折线；图例点击只更新本地状态并重绘。

## UI Behavior

- 初次普通查询后默认所有有数据的代币可见。
- 点击图例按钮后，对应曲线和图例状态同步切换；至少可保留全部隐藏状态，图表显示空状态。
- 切换“市值 / 币价”后，图表标题、纵轴数值、悬浮指引和最新值均使用对应字段。
- 更换计价代币、时间范围或聚合周期后重新请求数据，并恢复新结果中有数据代币的默认可见状态。
- 没有交易对或 candles 的代币显示为禁用图例，并保留服务端返回的原因。
- URL 继续保存 `network`、`quote`、`days`、`interval`；不再使用页面中的 `tokens` 作为可见性状态。

## Implementation Boundaries

- 数据查询和市值计算逻辑保持不变，只调整默认选择逻辑。
- 组合图和图例逻辑继续放在现有单页 `index.html` 中，不新增前端依赖或组件层。
- 复用现有 SVG 和 pointer guide 机制，调整为多系列共享坐标的实现。
- 不修改其它 dashboard。

## Verification

- Python 单元测试验证：未指定代币时返回全部非计价代币；显式代币筛选仍按原行为工作。
- 浏览器或 JavaScript 运行检查验证：组合图包含多个系列；图例点击改变对应折线显示；市值/币价切换读取 `market_cap` / `close`。
- 启动 dashboard 服务后在桌面和窄屏尺寸检查：代币下拉列表不存在，控制区不溢出，图例和曲线不重叠，空状态和禁用状态可读。
